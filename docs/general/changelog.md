## Records changes that matter to users, integrators, or other developers.

- Added a new feature
- Changed API behavior
- Added a new endpoint
- Fixed a bug
- Changed database schema in a way that affects deployment or migrations
- Added required configuration/settings
- Introduced breaking changes

---

### Example

```
## 1.3.0
- Added Google Calendar synchronization.
 
## 1.2.0
- Added client timeline events.
```
